# Photo Cube

A 3×3 twisty cube puzzle you cover with six of your own photos. Pick a photo for each side, press **Start** to scramble, and swipe rows to put the pictures back together.

Play it: https://mryeburn.github.io/photo-cube/

Photos are kept only in your own browser; nothing is uploaded. On iPhone, open the link in Safari and use Share → Add to Home Screen for an app icon.

Built with [three.js](https://threejs.org) (MIT license, see `three-LICENSE.txt`).
